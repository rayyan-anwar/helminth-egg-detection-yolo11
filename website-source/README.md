# Website source archive

This folder preserves the source files for the newer **Helminth Research Project Website** created in the Floot project workspace.

- `pages/_index.tsx` — research showcase page
- `pages/_index.module.css` — page styles and responsive layout
- `base.css` — typography and light/dark theme tokens

**Build/deployment note:** these files use the Floot project runtime and its preinstalled UI environment; they are an archival source snapshot, not a standalone Next.js application. The repository-root `index.html` remains the existing self-contained static website and is not overwritten by this addition.

The website reports the documented project metrics and limitations. It is a research communication page, not a clinically validated diagnostic system.
