# Academic enquiry package

This folder organises the non-DOCX materials prepared for an academic enquiry about the helminth egg detection study.

## Files

- `Oxford_Covering_Letter.md` — draft letter addressed to an appropriate faculty member or research group at the University of Oxford. Insert a contact email and recipient before sending.
- `REFERENCE_VERIFICATION.md` — DOI, title, publication metadata, and software release verification for manuscript references 1–7.
- `FINAL_SUBMISSION_CHECKLIST.md` — remaining scientific, repository, figure, and document checks.
