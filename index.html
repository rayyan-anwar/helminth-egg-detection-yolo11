05 / Mathematical foundations

The science behind the metrics.

Core equations used to understand object-detection evaluation.

Intersection over Union

IoU = Area(Bp ∩ Bg) / Area(Bp ∪ Bg)

Measures the overlap between a predicted bounding box and its ground-truth box.

Precision

Precision = TP / (TP + FP)

The fraction of predicted detections that are true positives under the matching protocol.

Recall

Recall = TP / (TP + FN)

The fraction of ground-truth objects detected under the matching protocol.

Mean Average Precision

mAP = (1 / C) Σ AP(c)

The mean of average precision across C classes at a specified IoU evaluation setting.

TP = true positive; FP = false positive; FN = false negative. AP summarises the precision–recall curve. mAP@50 evaluates at IoU 0.50; mAP@50:95 averages over IoU thresholds from 0.50 to 0.95. Exact values depend on the evaluation protocol and software implementation.
06 / Practical implementation

Inference, in Python.

A minimal example for using an existing checkpoint with Ultralytics.

python · inference.py YOLO11n / Ultralytics 
from ultralytics import YOLO

# Load the existing trained checkpoint
model = YOLO("models/best.pt")

# Run detection on a microscopy image
results = model.predict(
    source="path/to/microscopy_image.jpg",
    imgsz=320,
    save=True
)

# Inspect predicted boxes
for result in results:
    for box in result.boxes:
        class_id = int(box.cls[0])
        confidence = float(box.conf[0])
        xyxy = box.xyxy[0].tolist()

        print({
            "class_id": class_id,
            "confidence": round(confidence, 4),
            "box_xyxy": xyxy
        })

Run in a compatible Python environment with Ultralytics installed and the checkpoint present at the specified path. This example is illustrative and does not imply a particular prediction or confidence value.

07 / Research integrity

What the results do — and do not — establish.

Clear boundaries are essential to responsible scientific communication.

LIMITATIONS

Interpretation matters.

  • Object-detection metrics are not equivalent to clinical diagnostic sensitivity or specificity.
  • Performance on one dataset does not establish generalisation to other laboratories, microscopes, or populations.
  • Image-level split checks cannot prove specimen-level or patient-level independence.
  • The project is a research prototype, not a validated clinical diagnostic system.
REPRODUCIBILITY

Preserve the evidence.

  • Recorded baseline: YOLO11n, 15 epochs, image size 320, batch size 4, seed 42.
  • The original training run used CPU; later evaluation used a separate environment.
  • Exact reproduction requires matching checkpoint hash, package versions, and evaluation settings.
  • Keep the held-out test set separate from model selection and threshold tuning.
