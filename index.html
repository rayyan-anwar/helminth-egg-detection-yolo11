Mathematical foundations

Core object-detection evaluation concepts.

Intersection over Union

IoU = Area(Bp ∩ Bg) / Area(Bp ∪ Bg)

Measures overlap between a predicted box and its ground-truth box.

Precision

Precision = TP / (TP + FP)

The proportion of predicted detections that are true positives under the chosen matching criteria.

Recall

Recall = TP / (TP + FN)

The proportion of ground-truth objects detected under the chosen matching criteria.

Mean Average Precision

mAP = (1 / C) Σ AP(c)

Mean of the average precision values across C classes at a specified IoU evaluation setting.

TP = true positive, FP = false positive, FN = false negative. mAP@50 evaluates at IoU 0.50; mAP@50:95 averages across IoU thresholds from 0.50 to 0.95. Results depend on the evaluation protocol.

Inference example

Minimal Python example using an existing trained checkpoint.

from ultralytics import YOLO

# Load your trained checkpoint
model = YOLO("models/best.pt")

# Run inference on an image
results = model.predict(
    source="path/to/microscopy_image.jpg",
    imgsz=320,
    save=True
)

# Inspect detections
for result in results:
    for box in result.boxes:
        class_id = int(box.cls[0])
        confidence = float(box.conf[0])
        xyxy = box.xyxy[0].tolist()

        print({
            "class_id": class_id,
            "confidence": round(confidence, 4),
            "box_xyxy": xyxy
        })

Run this in an environment with the compatible Ultralytics package and your checkpoint file. Example code does not guarantee a particular result.

Limitations and scientific integrity

Interpret results carefully and preserve the held-out test set.

What these results mean

  • Metrics describe object-detection performance on the evaluated dataset.
  • They do not establish clinical diagnostic accuracy or clinical readiness.
  • Dataset-level separation does not prove independence of slides or specimens.
  • Performance may vary with image quality, acquisition conditions and external data.

Reproducibility notes

  • Baseline configuration: YOLO11n, 15 epochs, image size 320, batch size 4, seed 42.
  • Recorded original training used CPU; later evaluation used a separate environment.
  • Exact reproduction requires matching checkpoint, software versions and evaluation settings.
  • Do not tune model selection or thresholds on the held-out test set.
